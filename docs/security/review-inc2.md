## 2. Controls verified (no finding)

| Area | Evidence |
|---|---|
| SQL injection | Every statement reviewed uses `$n` parameters. Identifiers come from allowlists (`orderByClause`, `SORT`/`AUDIT_SORT` maps) or are validated (`IDENT` for alias/idColumn in `scopeFilter`). `rules.ts` interpolates only compile-time constants and typed lazy placeholders. LIKE inputs are escaped (`employees/repo.ts:57`, `admin/repo.ts:49`). |
| Authz / IDOR (Inc 2 routes) | Employees, settings, audit: `requireAction` with `admin: true` → Owner + completed 2FA; `IdParamSchema` UUID; `/employees/me` acts on `req.user.id`. Enrollment-token issuance requires password + TOTP re-auth and targets only another active, un-enrolled Owner. Denials carry no field values (`shared/errors.ts`, `assertAllowed`). |
| Hidden-record rule | `scopeFilter` emits an `EXISTS` over `access_facts` applied in `WHERE` before count/sort/page; `check` selects the same fragments as columns (one rule table). Owner hidden reads flagged for OI-05 audit. Duplicate shaping helper returns `existence_only` on any denial. |
| Email injection / real send | Recipients validated with Zod `.email()` + CR/LF refine; `{ name, address }` objects; subjects stripped of control chars and capped at 150; all vars control-stripped and HTML-escaped; link vars must be absolute http(s) without credentials; no custom headers; `disableFileAccess`/`disableUrlAccess` set. Content built at send time after the recipient-active re-check (C6/HR-7). Transport resolution: `NODE_ENV=test` → jsonTransport sink; `SMTP_HOST` empty → log; smtp requires `EMAIL_ALLOW_REAL_SEND=true` (worker refuses to start, API falls back to log). `requireTLS` when not `secure`; `logger`/`debug` off. |
| Test routes | `/api/test-support/*` and `/api/test-support/mail` are mounted only when `config.env === 'test'`; `resolveEnv` treats unset/unknown `NODE_ENV` as production; test clock `set/advance` throw outside test; in test only `TEST_DATABASE_URL` is honoured (pool points at port 1 otherwise). |
| Secrets in logs | Reset link logged only when `config.env === 'development'`; log transport prints template, recipient domain and delivery id only; `errorSummary` is name + message (no stack); worker start-up log omits host/user/pass; audit payloads hold ids only (`securityTokenId`, counts). `login.failed` email capped at 254 chars. |
| Identity (SEC-3) | AU-8: enrollment needs login password + one-time token (SHA-256 hashed, 24 h, single use, bound at `enroll/start`, consumed at `confirm`) + fresh password re-auth; CLI bootstrap never over HTTP. AU-13: AES-256-GCM with env key, key id per row, employee id as AAD, production refuses to start without `TOTP_ENC_KEY`, dev/test fixed public keys never in production. AU-9: 10 bcrypt-hashed single-use codes, shown once, same lockout as TOTP, E-04 emitted. AU-4/5 replay guard and session rotation kept. SE-4 seed guard present. |
