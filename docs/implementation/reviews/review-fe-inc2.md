## Verified OK
- **CSP:** `lib/csp.ts` and `proxy.ts` use a 128-bit per-request nonce with `strict-dynamic`, no script `unsafe-inline` in production, and `frame-ancestors 'none'`. `x-nonce` is overwritten server-side, so the client cannot spoof it. `ThemeScript` carries the nonce. `/reset-password` gets `no-referrer` from both the header and the meta tag.
- **CSRF:** `apiFetch` sends `X-CSRF-Token` on POST/PUT/PATCH/DELETE (cookie first, then the memory token from `/me`) with `credentials:'same-origin'`.
- **Dev flags:** `devFlags.ts` and `fixtureMode.ts` are both forced off when `NODE_ENV==='production'`, and no page imports `src/fixtures` (see CR1-05 for the bundle check).
- **Secrets:** none in `src/`. The seed password exists only behind `DEV_PERSONAS_ENABLED`.
- **Focus trap:** `useFocusTrap` handles initial focus, Tab wrap and return-focus correctly for a single modal.
- **Nav:** shell, sidebar and mobile tab bar meet the 44 px targets. Navy dark tokens are correct in `globals.css` (`#0B1A36`/`#122953`).
- **SHR-011:** `PermissionDenied` matches `previews/45 … Role denied.png`.
- **FE3 and FE5:** pages use `PolicyPendingChip`, and I found no hex colours.
