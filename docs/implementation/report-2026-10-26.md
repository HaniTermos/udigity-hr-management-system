The full production stack ran on alternate ports, then was torn down. Components: Postgres, backend, worker, frontend, and nginx with TLS. All 16 checks passed:
- **Health:** `/healthz`, `/readyz` (DB connected) and `/health/worker` (heartbeat) all respond, and all are hidden at the edge.
- **Routing:** `/login` serves over TLS, and HTTP redirects to HTTPS.
- **Security headers:** nonce-based CSP with strict-dynamic, HSTS, nosniff, and a correct Referrer-Policy. The fix was to exclude the frontend test files from the production typecheck.
