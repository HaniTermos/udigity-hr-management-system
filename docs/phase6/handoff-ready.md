## Pending decisions stay visibly pending

Every pending policy (DEC-xxx, R-xx, OQ-xx, B3-Qxx, D4, F2/F3, "Proposed", "No DEC ID") must stay **visibly pending** in the build: label it or put it behind a switch. Never ship one alternative as if it were decided. Where a frame shows alternatives (DEC-026 A/B/C, DEC-006 Alt A/B, R-11 a/b, DEC-011 A/B, DEC-005 Alt 1/2), build them behind a flag and select none. **"Accepted keeps reservation?"** (SCR-CC-003) is an open Owner question, so do not settle it in code. **"Mark reviewed"** (SCR-OWN-012) waits for the user to confirm the AR-13 departure.
